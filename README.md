# Student Academic Record System

A modular C command-line application for managing student academic records. Designed with modular architecture using structures, dynamic file handling (CSV), and pointers.

## Features

- **Add Student Record:** Add student entries with ID, Name, GPA, and Credit Hours.
- **Display Records:** Display all student records formatted cleanly in a table view.
- **Search:** Instant record lookup using Student ID.
- **File Persistence:** Automatically saves and loads record data to/from `students.csv`.
